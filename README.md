# BeerAggregation — ТСД АТОЛ Smart M20

Приложение для терминала сбора данных: сканирование паллет и коробов пива,
ведение прогресса по паллете, формирование отчёта и файла «бой».

**Целевое устройство:** АТОЛ Smart M20 (Android 13, MT6769, 4.2" 1280×720,
2D-сканер N6602-W2).

## Как это работает

1. Оператор загружает файл агрегации (бутылка → короб → паллета, разделитель — таб).
2. Сканирует ШК паллеты — она «открывается».
3. Сканирует ШК коробов этой паллеты. Каждый скан подтверждается звуком,
   вибрацией и цветовой вспышкой:
   - зелёная вспышка + один сигнал + короткая вибрация — короб принят;
   - красная вспышка + сигнал ошибки + тройная вибрация — дубликат, чужой короб
     или короб отсутствует в агрегации.
4. По кнопке «Сформировать отчёты» сохраняются два файла:
   - `report.txt` — отсканированные короба;
   - `boi.txt` — «бой» (вся агрегация минус отсканированное).

## Сканер

Сканер ТСД работает в режиме **USB HID Keyboard**: он «печатает» штрихкод как
текст и завершает ввод нажатием Enter. Приложение принимает код в поле ввода,
которое удерживается в фокусе автоматически — касаться экрана при сканировании
не нужно.

## Где лежат файлы на устройстве

```
/sdcard/Download/BeerAggregation/          <- сюда кладётся файл агрегации
/sdcard/Download/BeerAggregation/report/   <- сюда пишутся отчёты
    report.txt
    boi.txt
```

При первом запуске приложение попросит разрешение **«Доступ ко всем файлам»** —
без него Android 13 не даёт читать и писать в папку `Download`.

## Сборка APK

APK собирается автоматически в облаке GitHub Actions — на компьютере ничего
устанавливать не нужно.

1. Создайте репозиторий на GitHub.
2. Отправьте туда проект (см. «Публикация проекта» ниже).
3. Откройте вкладку **Actions** — сборка запустится сама.
4. Через ~40–60 минут заберите APK: страница сборки → блок **Artifacts** →
   `beeragg-apk`.

Готовый файл: `bin/beeragg-0.2-arm64-v8a-debug.apk`.

## Установка APK на терминал

1. Скопируйте APK на ТСД (USB-кабель или карта памяти).
2. На терминале: **Настройки → Безопасность → Неизвестные источники** — разрешить.
3. Откройте APK файловым менеджером и подтвердите установку.
4. При первом запуске выдайте разрешения: память и **Доступ ко всем файлам**.
5. Положите файл агрегации в `/sdcard/Download/BeerAggregation/`.

## Проверка логики без терминала

```bash
py -3.13 test_core.py    # логика агрегации
py -3.13 test_ui.py      # сборка интерфейса
py -3.13 test_e2e.py     # сценарии сканирования целиком
```

## Файлы проекта

|------|------------|
| `main.py` | Интерфейс, сканирование, звук/вибрация, отчёты |
| `core.py` | Логика агрегации: паллета → короб → бутылка, отчёт и «бой» |

| `sounds/` | Звуковые сигналы успеха и ошибки |
| `.github/workflows/build.yml` | Автосборка APK в GitHub Actions |
